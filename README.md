# 🌾 Crop Yield Prediction System

## Overview
This project predicts crop yield using Machine Learning based on soil and environmental parameters.

## Features
- Crop Yield Prediction
- Interactive Streamlit Dashboard
- Smart Recommendations
- Region-wise Analysis
- Season-wise Analysis

## Technologies
- Python
- Streamlit
- Pandas
- XGBoost
- Plotly

## Model Performance
XGBoost R² Score: 0.98

## Run Project

pip install -r requirements.txt

streamlit run app11.py
